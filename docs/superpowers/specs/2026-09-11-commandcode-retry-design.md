# CommandCode 请求自动重试设计

## 目标

为 `/alpha/generate` 上游请求增加自动重试机制。单次调用最多尝试 5 次，所有上游失败类型均可触发重试，重试间隔固定为 100ms。

## 方案

在 `src/commandcode/client.ts` 的 `stream` 客户端内部包裹完整的单次请求流程。每次尝试复用同一个临时工作目录、请求会话 ID 和已构造的请求 payload，但重新调用上游接口。HTTP 非 2xx、网络异常、超时，以及响应解析阶段发现的空响应、畸形 NDJSON 或不完整流都视为失败。

成功读取终止事件后立即返回，不再重试。达到 5 次尝试仍失败时抛出最后一次错误，保留现有 `CommandCodeUpstreamError` 的状态码和响应体。调用方的 `AbortSignal` 被取消时不等待、不发起后续重试。

## 可观测性

保留现有请求和响应日志；每次失败继续记录失败日志，并记录当前尝试次数。API key 和请求中的敏感内容仍不得进入日志。

## 测试

扩展客户端测试覆盖：失败后成功、连续 5 次失败、解析失败后重试、成功时只调用一次，以及调用方取消后不继续重试。现有请求格式、错误映射、清理临时目录和日志脱敏测试必须继续通过。
